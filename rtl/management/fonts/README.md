# Management UI font

`manager_font.mem` is the 8x16 bitmap data for ASCII character slots 0-127,
generated from **Spleen 8x16 version 2.2.0** by Frederic Cambus.

- Upstream: <https://github.com/fcambus/spleen>
- Source file: `spleen-8x16.bdf`
- License: BSD-2-Clause; see `Spleen-LICENSE.txt` in this directory.

Only the management overlay uses this font. The emulated CoCo character ROM
and its software-visible appearance remain unchanged.
